# Support

VectorRF Lab is an open-source laboratory project rather than a supported commercial instrument.

For reproducible defects, use GitHub Issues and include your Python version, operating system, VectorRF Lab version, configuration/steps, expected result, and actual result. For usage questions, use GitHub Discussions if the repository has Discussions enabled; otherwise an issue with a clear `question` prefix is fine.

For suspected security vulnerabilities, follow `SECURITY.md` and do not publish exploit details or secrets in a public issue.
