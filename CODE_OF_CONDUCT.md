# Code of Conduct

VectorRF Lab contributors and participants are expected to keep project spaces constructive, technical, and respectful.

Be considerate when reviewing work, focus criticism on code and ideas rather than people, welcome questions asked in good faith, and avoid harassment, discrimination, threats, doxxing, sexualized conduct, or deliberately disruptive behavior.

Maintainers may edit or remove comments, issues, pull requests, or other contributions that violate these expectations, and may temporarily or permanently restrict participation when necessary to protect the project community.

If you need to report conduct privately, use an available private maintainer contact channel rather than posting sensitive details publicly. If no private channel is published, open a minimal issue asking how to contact the maintainers without including the sensitive details.
